# Keywords — Private Client Campaigns

Match types in this doc:
- `[exact]` = Exact match
- `"phrase"` = Phrase match
- `broad` (no punctuation) = Broad match

**Rule at launch:** Start with **Phrase + Exact only**. Add Broad match in Week 3 once negative-keyword lists are solid.

## Negative keyword matching strategy

- **Apply the shared list as Phrase match negatives** so `immigration lawyer near me` triggers the negative but legitimate queries like `immigration packet help` still come through.
- Review the **Search Terms report** weekly. Any junk query → add as negative.
- After 4 weeks, prune keywords with <1% CTR and <0.5% conversion rate from the positive lists.
