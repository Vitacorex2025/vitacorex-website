VitaCoreX PDF + Email Delivery Diagnosis Report

1) Exact root cause of the PDF failure
- The PDF files themselves are present and reachable in the deployed asset path:
  - assets/pdf/lead-magnet-healthcare.pdf
  - assets/pdf/healthcare-cfo-brief.pdf
  - assets/pdf/dental-institutional-deck.pdf
  - assets/pdf/precollection-executive-review.pdf
- The broken part was the JavaScript click/open flow for the gated PDF action.
- The previous code intercepted the PDF click, opened about:blank on desktop, then waited for a hidden-iframe form submit helper to "succeed".
- That helper did not wait for a real provider response. It resolved optimistically after 1.8 seconds even if the provider flow had not actually completed.
- Result: the browser could be left on a blank pre-opened tab/window, which matches the observed blank-page / failed-load behavior.

2) Exact root cause of the email failure
- The JS-driven submission flow for the PDF gate and web-project modal used a hidden iframe plus an optimistic timer instead of verifying a real provider success response.
- Because of that, the UI could show success even when delivery had not actually been confirmed.
- The notification destinations were also inconsistent across site forms:
  - some forms pointed to Gmail
  - some pointed to mail.com
- This created an unreliable owner-notification path and made delivery troubleshooting harder.

3) What was changed
- Replaced the hidden-iframe optimistic submit flow in JS with a real FormSubmit AJAX flow that waits for an actual HTTP/provider response before treating the submit as successful.
- Removed the about:blank pre-open PDF pattern.
- PDF open now resolves the real absolute PDF URL and opens it directly; if a new tab is blocked, it falls back to same-tab navigation.
- Normalized the JS-driven notification target to:
  vitacorexllc@gmail.com
- Updated the fallback HTML form actions for the PDF gate and web-project modal to the same Gmail destination.
- Added form metadata for source identification and exact form URL in the submission payload.
