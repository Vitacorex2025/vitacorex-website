## Treatment guidance

- **Style**: low saturation, slight contrast, cool-neutral palette. Avoid
  full B&W — preserves meaning at the cost of mood.
- **Hero darken**: 35-45 %.
- **Card with text overlay darken**: 45-60 %.
- **Crop**: hero 16:9 / 16:10 ; quick-access 4:5 / 3:4 ; leak 3:2 / 16:10 ;
  case studies 3:2.
- **Mobile**: do NOT overlay small text on busy document photos. On
  iPhone use image-on-top, text-below pattern with min card height
  220-260 px.
- **Optimisation**: convert to WebP/AVIF for production
  (`cwebp -q 78 -m 6` is a sane default). Hero 2200-2600 px wide,
  cards 900-1400 px, thumbnails 800-1200 px.
- **Filename convention preserved**: hero-*, quick-*, leak-*, case-* —
  matches sections in the homepage layout.
