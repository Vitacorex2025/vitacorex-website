VitaCoreX v210 rewrite summary

What was broken
- The live site at vitacorexllc.com is currently rendering a degraded header state: the top renders clocks/language/menu while much of the expected nav/hero UI is not presenting cleanly.
- Earlier builds mixed multiple generations of header/menu/dock CSS and JS, which made mobile menu state, header geometry, and dock sizing unreliable.

What was rewritten from scratch
- Replaced the entire header architecture with an isolated system using new classes:
  - desktop two-row header
  - mobile compact control bar + mobile menu
- Replaced the bottom action dock with a new isolated desktop/mobile dock system.
- Added a dedicated ui-shell.css and ui-shell.js so header/menu/dock no longer depend on old broken selectors.

Why the buttons/menu were failing
- Old builds reused the same selectors (.site-header, .menu-btn, .mobile-nav, dock selectors) across multiple generations of code.
- Different controllers were toggling the same open/compact states, so click behavior and layout state conflicted.

What was simplified
- New header/menu/dock are isolated from old CSS/JS by using new root classes.
- Old translation/clocks/forms/calculators remain intact because existing site.js still handles lang/clocks/forms.
- Mobile menu now has one controller only: assets/js/ui-shell.js

Files added
- assets/css/ui-shell.css
- assets/js/ui-shell.js

Acceptance targets addressed in this rewrite
- mobile menu logic isolated
- desktop header rebuilt cleanly
- mobile header rebuilt compactly
- bottom dock reduced and structured into stable desktop/mobile layouts
