How the site handles essential functionality, analytics consent, and configured measurement tools.

The site already had a consent banner. This page makes the consent logic and tracker categories explicit.

Company-first positioning

These pages support the corporate lane first: recovery design, documentation control, and cleaner handoff before outside cost expands.

How cookies are used

The site uses essential functionality plus optional analytics and marketing measurement tools. Optional tools are intended to load only after consent.

Consent choices

  • Essential only: basic site operation without optional analytics or marketing tags.
  • Analytics only: essential functionality plus analytics-focused measurement.
  • Accept all: essential, analytics, and any configured campaign/marketing measurement tools.

Configured tracker slots

The site is prepared for Google Analytics 4, Google Tag Manager, Microsoft Clarity, Hotjar, Meta Pixel, LinkedIn Insight Tag, and Apollo website tracking. Whether each tool is active depends on the current deployment settings and consent choice.

Managing consent

You can manage consent through the banner when it is shown. Browser settings can also be used to control or clear cookies.
