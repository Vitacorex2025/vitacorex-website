VitaCoreX Analytics & Tracking Install Guide
===========================================

Included in this package
------------------------
1. Google Analytics 4 is prefilled with:
   GA4 Measurement ID: G-E08EE1KSQQ

2. Apollo website tracker is prefilled with:
   Apollo App ID: 69a7b325debb1e000d36d253

3. Consent-aware scaffolding is included for:
   - Google Tag Manager
   - Microsoft Clarity
   - Hotjar
   - Meta Pixel
   - LinkedIn Insight Tag

4. Event tracking added:
   - consultation_click
   - form_submit
   - contact_form_submit
   - consultation_request
   - pdf_download
   - revenue_calculator_use
   - dso_calculator_use
   - roi_calculator_use

Where to edit IDs
-----------------
Every HTML page contains this config near the bottom before assets/js/site.js:

window.VCX_TRACKING_IDS=window.VCX_TRACKING_IDS||{
  ga4:"G-E08EE1KSQQ",
  gtm:"",
  clarity:"",
  hotjarSiteId:"",
  hotjarVersion:6,
  metaPixel:"",
  linkedInPartner:"",
  apolloAppId:"69a7b325debb1e000d36d253"
};

Only GA4 and Apollo are already active.
To activate the others, paste your real IDs in the empty quotes.

Recommended install steps
-------------------------
1. Unzip this package.
2. Upload all files to your hosting, replacing the old files.
3. Open the website once in an incognito/private window.
4. Accept the cookie banner for analytics/marketing.
5. Verify tools.

How to verify GA4
-----------------
1. Open Google Analytics.
2. Go to Reports -> Realtime.
3. Visit your website on phone or desktop.
4. You should see at least 1 active user.

How to verify Apollo
--------------------
1. Open the site in a private/incognito tab.
2. Visit a few pages.
3. Check Apollo website visitor tracking dashboard for activity.

How to activate other trackers
------------------------------
Google Tag Manager:
- Put your GTM container ID into gtm:"GTM-XXXXXXX"

Microsoft Clarity:
- Put your project ID into clarity:"YOUR_CLARITY_ID"

Hotjar:
- Put your numeric site ID into hotjarSiteId:"1234567"

Meta Pixel:
- Put your pixel ID into metaPixel:"1234567890"

LinkedIn Insight:
- Put your partner ID into linkedInPartner:"123456"

Important consent behavior
--------------------------
- Essential only: no analytics/marketing scripts load.
- Analytics: loads GA4, Apollo, Clarity, Hotjar, and GTM.
- All cookies: additionally loads Meta Pixel and LinkedIn Insight.

Extra notes
-----------
- If you use GTM, avoid duplicating GA4 inside both GTM and direct gtag unless you intend to.
- Apollo is being loaded from the provided snippet, but routed through the same consent system.
- Events are sent when visitors click consultation CTAs, submit forms, download PDFs, and interact with calculators.
