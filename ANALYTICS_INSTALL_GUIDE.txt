VitaCoreX Analytics Installation Guide
=====================================

Live stack in this package
--------------------------
1. Google Analytics 4
2. Microsoft Clarity
3. Meta Pixel
4. LinkedIn Insight Tag
5. Consent-aware loading
6. Attribution persistence for UTM and click IDs

Current defaults
----------------
The shared analytics layer now lives in:

assets/js/site.js

The default configuration object is:

VCX_TRACKING_DEFAULTS

Current GA4 default:
- ga4: G-E08EE1KSQQ

Other vendor IDs are blank until you add production values:
- clarity
- metaPixel
- linkedInPartner

How to set IDs
--------------
Option 1: Edit the shared defaults in assets/js/site.js.

Option 2: Define a runtime override before assets/js/site.js loads:

window.VCX_TRACKING_IDS = {
  ga4: "G-XXXXXXXXXX",
  clarity: "CLARITY_PROJECT_ID",
  metaPixel: "123456789012345",
  linkedInPartner: "123456",
  linkedInConversions: {
    confidential_review_click: "111111",
    company_intake_submit: "222222",
    executive_brief_submit: "333333",
    individual_service_request_submit: "444444",
    careers_submit: "555555"
  }
};

LinkedIn note
-------------
The Insight base tag supports audience building and remarketing once linkedInPartner is present.

If you want event-level LinkedIn conversion tracking, provide conversion IDs inside:

linkedInConversions

If no conversion IDs are provided, the site still loads the Insight tag after full consent, but custom LinkedIn conversion events remain safely disabled.

Consent behavior
----------------
- Essential only: no analytics or marketing vendors load.
- Analytics only: GA4 and Clarity load.
- Accept all: GA4, Clarity, Meta Pixel, and LinkedIn Insight Tag load.

No vendor script should be installed separately in the HTML if you are using this shared layer.
Do not add duplicate GA4, Meta Pixel, or LinkedIn snippets outside assets/js/site.js.

Validation checklist
--------------------
1. Open the site in a fresh private window.
2. Confirm the consent banner appears before any optional vendors load.
3. Accept Analytics only and verify:
   - GA4 loads
   - Clarity loads
   - Meta and LinkedIn do not load
4. Accept all and verify:
   - GA4 loads
   - Clarity loads
   - Meta Pixel loads
   - LinkedIn Insight loads
5. Trigger the main CTA, executive brief gate, and form submissions.
6. Confirm the events appear in the relevant vendor tools.

Implementation notes
--------------------
- Apollo, Hotjar, and GTM were removed from the live tracking path in this rebuild to avoid duplicate firing and reduce vendor sprawl.
- Missing IDs fail safely: the site will not throw errors if any vendor ID is blank.
