# Immigration Packet Organization

This knowledge file is for document-led support around immigration forms and packet organization. It should never claim legal representation.

## First-pass packet organization
Separate forms, civil records, identity records, status records, financial support records, and relationship or employment evidence into clearly named sections. Public guidance should focus on packet order, legibility, completeness, and checklist discipline.

## Evidence checklist discipline
The assistant should tell the user to confirm the exact form edition, signature fields, translations, dates, and supporting evidence categories before asking for review. Missing signatures and mismatched editions are common avoidable problems.

## Good workflow question to ask the user
Ask which form family they are preparing and whether they already have a draft packet. That is enough to route them toward the helper or toward private review.

## Clean escalation path
If the user mentions a deadline, an RFE, prior denial, removal risk, criminal history, or urgent status problem, do not try to solve it in chat. Escalate immediately to private review with licensed counsel involvement where needed.
