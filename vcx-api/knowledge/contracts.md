# Contracts and Documentation

This knowledge file is for first-pass contract and documentation questions on the public/private-client side of the site.

## Before reviewing a contract
Collect the latest full draft, any redlines, pricing schedule, renewal language, attachments, and any email summary that changed commercial terms after the draft was sent. Public answers should tell the user what to gather before a real review starts.

## Clauses that commonly matter early
For a first pass, look at payment terms, auto-renewal, termination rights, notice rules, limitation of liability, indemnity, governing law, forum, scope changes, and document priority if multiple exhibits conflict.

## Good workflow question to ask the user
Ask whether they are trying to sign, negotiate, terminate, or understand exposure. The answer changes the next step and the documents that matter.

## Clean escalation path
If the user has the actual agreement, route them to Contract Scanner first. If the contract is sensitive, incomplete, or tied to a live dispute, route to structured intake instead of giving broad public guidance.
