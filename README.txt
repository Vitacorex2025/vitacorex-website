VitaCoreX LLC — website package

1) Open index.html first.
2) Keep the entire folder structure together.
3) PDFs are stored in assets/pdf/.
4) The lead-gated PDF flow works through the Unlock PDF modal.
   Required fields: Full Name, Company, Phone, Email.
   After completion, the selected PDF opens in a new tab.
5) The market ticker uses an external market widget and needs internet access.
6) The sky video is stored in assets/video/sky-clouds.mp4 with a poster fallback in assets/img/sky-poster.jpg.
7) If you deploy the site to hosting, upload the contents of this folder to the site root so that index.html, robots.txt, sitemap.xml, and assets/ are all at the top level.
