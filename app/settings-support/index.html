API configuration

Workspace rules

Purpose-built for operational control and clear client use.
  • Ordinary matter intake accepts source evidence only. Users are not asked to upload DOCX templates for normal packet generation.
  • Processing runs only after the user explicitly clicks Start Processing.
  • The internal template library is applied automatically at generation time; template replacement belongs in admin-only template management.
  • Generated Word outputs are shown in the Exports screen, not hidden in logs.
  • Operational support only: attorney review remains outside the software.
